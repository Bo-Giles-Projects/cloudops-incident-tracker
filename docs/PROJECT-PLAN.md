# Project plan: CloudOps Incident Tracker

## Goal
Build and operate a small production-style full-stack web application to demonstrate skills in Linux, networking, containers, AWS, CI/CD, infrastructure as code, observability and incident response.

## Phase 1: Local application
- [ ] Install Node.js 22+, Docker Desktop, VS Code
- [ ] Start PostgreSQL with Docker Compose
- [ ] Start API and React web app
- [ ] Create, view and resolve an incident
- [ ] Run API tests and frontend build
- [ ] Create a GitHub repository; commit the starter
- [ ] Add screenshots and document obstacles/resolutions

## Phase 2: Containers
- [ ] Write Dockerfiles for API and web
- [ ] Serve production web build with Nginx
- [ ] Create full-stack Docker Compose setup
- [ ] Add smoke tests and health checks

## Phase 3: CI/CD
- [ ] Add linting and coverage
- [ ] Add container image builds and vulnerability scanning
- [ ] Publish versioned artifacts
- [ ] Automate deployment with approvals and rollback plan

## Phase 4: AWS and Terraform
- [ ] Draw architecture and estimate costs first
- [ ] Configure AWS budgets and account security
- [ ] Write Terraform for networking and compute
- [ ] Deploy securely with least-privilege IAM and managed secrets
- [ ] Record deployment steps and costs

## Phase 5: Operability
- [ ] Add application logging and metrics
- [ ] Create CloudWatch dashboards and alerts
- [ ] Test failure/recovery scenarios
- [ ] Document runbooks and lessons learned
